## 项目简介

本仓库持续追踪 **DSP（桥粒斑蛋白）基因缺陷相关心肌病**的治疗前沿，覆盖从病理机制到临床转化的完整证据链。主文档为 [`DSP-Cardiomyopathy_Frontier-Therapeutics-Tracker.md`](./DSP-Cardiomyopathy_Frontier-Therapeutics-Tracker.md)，由原始追踪记录（16 条条目）规范化整理而成，并整合 *Advanced Science* (2026) POSTN–CCL3 前馈信号环研究作为独立重点章节。

| 章节 | 内容 |

## 证据级别定义

| 级别 | 含义 |
|---|---|
| A | 人体随机对照 |
| B | 人体病例或队列 + 体内机制 |
| C | 动物体内药效 |
| D | 体外或机制验证 |
